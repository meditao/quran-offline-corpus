# 01_raw

Doğrulanmış ham Kur'an metni ve temel metadata burada tutulur.

Kurallar:
- Kaynak ve lisans doğrulanmadan veri eklenmez.
- Ham dosyalar mümkün olduğunca değiştirilmeden saklanır.
- Her dosyanın kaydı `SOURCES.md` içinde bulunur.
- Normalizasyon gerekiyorsa ham dosyanın üzerine yazılmaz; türetilmiş sürüm ayrı dosyada tutulur.
