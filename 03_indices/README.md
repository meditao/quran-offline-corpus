# 03_indices

Ham veri ve morfoloji katmanından türetilen indeksler burada tutulur.

Örnekler:
- kök indeksi
- lemma indeksi
- sözcük frekansları
- ayet-kelime eşlemesi
- sure/ayet dağılım tabloları

Bu katmandaki dosyalar yeniden üretilebilir olmalı; üretim yöntemi `08_scripts/` altında belgelenmelidir.
